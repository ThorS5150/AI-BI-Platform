# 03 Scope and Limits

## In scope
- Synthetic dataset on automotive sales in Quebec
- Pipeline with three layers in Databricks
- One dashboard in Power BI or Tableau
- RAG over a small set of own sample documents
- One LangGraph agent with three tools
- Governance artifacts according to ISO/IEC 42001

## Deliberately out of scope
- Real-time streaming
- Production authentication and multi-tenancy
- Real customer data (privacy, Law 25)
- Fine-tuning of own language models
- Production operation with SLA

## Limits
- Free Edition: limited compute and features
- Synthetic data does not reflect real market patterns
